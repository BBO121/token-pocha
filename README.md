# 토큰포차 (Token Pocha)

토큰포차 웹 페이지를 만드는 HTML, CSS, JavaScript 퍼블리싱 프로젝트입니다.

## 프로젝트 목표

- HTML로 페이지의 의미와 구조를 설계합니다.
- CSS로 화면 디자인과 반응형 레이아웃을 구현합니다.
- 필요한 상호작용을 JavaScript로 추가합니다.

## 로컬 실행

Node.js 18 이상에서 프로젝트 폴더를 열고 `npm start`를 실행합니다. 의존성 설치나 빌드가 필요 없습니다.

주소: http://127.0.0.1:4173

서버는 이 컴퓨터의 루프백 주소에서만 열리며, 허용된 화면 파일만 제공합니다. 종료는 실행한 터미널에서 Ctrl+C를 누릅니다. 포트를 바꾸려면 PORT 환경 변수를 지정합니다.

## 구현된 기능

- 어두운 포차 분위기의 반응형 대시보드와 상태 배너
- 93명 캐릭터의 이름·성격 검색, 소속·설정 상태 필터, 상세 모달
- 관계 카드와 연결된 캐릭터 상세 보기
- 에피소드, 직원·메뉴 노트, 연대기
- 확정(canon), 초안(draft), 확인 필요(needs-confirmation) 구분
- 전체 JSON 편집과 검증, 브라우저 저장, JSON 내보내기·가져오기

## 데이터와 저장

`data/archive.json`이 최초 원본입니다. 편집실의 저장은 현재 주소의 브라우저 localStorage에만 적용되며 저장소 파일을 바꾸지 않습니다. JSON 내보내기로 백업한 뒤 원본을 갱신하려면 해당 파일을 직접 교체합니다. 가져오기는 검토 후 저장을 눌러야 적용됩니다. 저장소나 브라우저 데이터를 지우기 전에 JSON 백업을 권합니다.

리센드·크티·사파리·일러레·홍보이모는 여성입니다. 일러레/Illustrator, YouTube Red/Premium, Twitter/X는 동일 인물로 통합했습니다. 직원 두 명은 미확정이고 메뉴 및 예시 에피소드는 초안입니다. 1989는 연대기 범위의 시작점이며 사건 날짜를 임의로 확정하지 않았습니다. 성격이 미정인 인물은 확정된 프로필과 별도로 확인 필요 메모를 표시합니다.

로그인·클라우드 동기화·데이터베이스는 없습니다. 화면의 PRIVATE 표시는 인증 기능이 아닙니다. 공개 호스팅이나 Pages 설정 없이 로컬에서 사용합니다. 외부 폰트·CDN·분석 서비스도 사용하지 않습니다.

## 확인

`npm run check`로 JavaScript 문법, 명단·성별·중복·관계 무결성, JSON 검증과 렌더러를 확인합니다.

## 개발 방식

HTML과 CSS로 구현할 수 있는 부분부터 작업하고, 필요한 경우 JavaScript를 사용합니다.
