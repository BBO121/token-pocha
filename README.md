# 토큰포차 · World Archive

HTML · CSS · JavaScript로 만든 다크 브라운 / 뮤트 골드 세계관 아카이브입니다. GitHub Pages에서 공개 열람하고 로컬에서도 실행할 수 있습니다.

## 실행

Node.js 18 이상에서 `npm start` 후 http://127.0.0.1:4173 에 접속합니다. 서버는 루프백 주소에만 바인딩하며 허용된 자산만 제공합니다. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다. 의존성 설치나 빌드는 필요 없습니다.

## 화면

- 홈: “내 머릿속 어딘가, 작은 포차 하나.” 소개와 통계 4개, 세계관 서랍 7개, 오늘의 단골들·설정 메모. 최초 대시보드 구성을 정보 밀도에 맞춰 복구했습니다.
- 도감: 12개 분류별 접이식 세로 목록. 이름·영문·별명·설명 검색과 분류·상태 필터.
- 위키: `character.html?id=c001` 같은 독립 주소. 프로필 표, 개요, 성격과 설정, 인간관계, 설정 메모, 인물 연대기.
- 관계도: 인물 검색/선택, 연결 인물을 선택해 중심 변경, SVG 관계선과 라벨, 하단 관계 목록.
- 가문과 소속: 가문·조직·모임별 고정 관계도와 구성원 링크. 여러 집단에 중복 소속 가능. 집단 소속만으로 혈연이나 상하관계를 만들지 않습니다.
- 에피소드: 작은 제목·분류·상태 목록과 대화 모달. X / 바깥 클릭 / Esc 닫기, 포커스 복귀와 긴 내용 스크롤.
- 토큰포차: 포차 소개 / 바 카운터 / 메뉴판 / 단골석 / 이야기 게시판. 직원은 위키, 에피소드는 모달로 연결됩니다.
- 연대기: 실제 기술사와 기존 세계관 관계를 하나의 세로 목록으로 정렬. 인물·분류·사건 유형·기록 구분 필터. 실제 기술사 출처 링크 제공.
- 편집실: JSON 검증, 브라우저 저장, 가져오기·내보내기, 원본 불러오기 유지.

본문 13px, 연대기·표·목록 12px, 보조 11px, 섹션 제목 15~16px, 페이지 제목 20~22px를 기준으로 합니다. 기존 로컬 서체를 유지하며 외부 CDN은 사용하지 않습니다.

## 정전과 데이터 점검

작업 시작 시 데이터와 최초 구현 커밋은 모두 **고유 인물 93명 / 12개 분류 / 분류 소속 합계 94건**이었습니다. Illustrator가 두 분류에 속합니다. 요청의 95명 원본 명단은 현재 자료에서 확인되지 않아 두 명을 임의로 추가하지 않았습니다. 95→93의 차이가 어떤 통합에서 생겼는지는 확정할 수 없습니다. `identityAudit`에 이 한계를 남겼습니다.

93명의 기존 id·이름·성별·설명·설정 메모를 보존했습니다. Illustrator/일러레, YouTube Red/Premium, Twitter/X, Windows의 버전은 각각 동일 인물입니다. 여성은 Illustrator·홍보이모·Resend·Ctee·Safari 다섯이며 공오의 성별은 미정입니다. 기존 관계를 유지하고 사용자 확정 사항인 Fold–Flip 쌍둥이, Claude–Supabase 상사 관계, Supabase가 종연을 소중히 여기는 관계를 명시했습니다.

종연의 인물별 호칭 전체 표는 원본에 없으므로 만들지 않았습니다. 설명에 있는 삼촌·홍보이모·도련님 등은 보존했습니다. 별도 가문·가족·지위 필드가 없으면 미정으로 표시합니다. 상세의 성격과 설정은 기존 소개를 사용하며 새로운 성격은 추가하지 않습니다.

추가 직원 두 명, 메뉴 이름·가격, 단골석과 방문 설정은 미정입니다. 기존 초안 에피소드 한 편과 메뉴 초안을 데이터에서 보존하며 새로운 에피소드는 창작하지 않았습니다. 에피소드 분류가 없으면 미정으로 표시합니다.

연대기의 `kind`는 `history`(실제 기술사) / `fiction`(세계관 설정), `type`은 사건 유형, `characterIds`는 관련 인물입니다. 실제 기록은 `source`에 공식 출처를 기록합니다. 연도만 확인한 사건은 연도만, 날짜가 확인된 사건은 `date`까지 기록합니다. 세계관 관계의 시작 시점은 모두 연도 미정입니다. 과거 1989년 범위 안내 문구는 사건이 아니므로 `referenceNotes.legacyChronology`에 보관했습니다. 모든 인물의 실제 기술사 전체를 망라한 것은 아니며 검증한 기록부터 수록합니다.

## 저장과 공개 배포

`data/archive.json`은 원본입니다. 편집실 저장은 현재 브라우저의 localStorage만 바꿉니다. 가져오기와 내보내기는 기존 데이터를 보존하며, 이전 브라우저 저장본이 있으면 그대로 열고 최신 원본과 다를 수 있다는 안내를 표시합니다. 최신 원본은 편집실의 '원본 데이터 불러오기'로 검토 후 저장할 수 있습니다. 원본 불러오기는 자동 저장하지 않습니다.

GitHub 저장소와 Pages는 공개 열람 대상입니다. 로컬 서버는 루프백 전용입니다. 설정 편집실의 저장은 방문자의 브라우저에만 적용되며 다른 방문자나 저장소에는 반영되지 않습니다. 인증이나 서버 데이터베이스를 제공하지 않습니다.

## 검증

`npm run check`: 문법, 93명·12개 분류·성별·동일 인물·관련 id, 전체 위키 렌더러, 잘못된 JSON·관계·출처 거절을 확인합니다.

`browser-check.cjs`: Playwright와 Chrome이 설치된 환경에서 저장소 상위 폴더에서 `node token-pocha/browser-check.cjs`를 실행합니다. Playwright 모듈의 별도 경로는 `TOKEN_POCHA_PLAYWRIGHT`로 지정할 수 있습니다. 자체 로컬 서버(4175)를 실행·종료하며 별도 테스트 브라우저만 사용합니다. 캡처는 무시되는 `test-results/`에 저장합니다. 도감, 독립 위키/새로고침/복귀, 관계도, 모달, 연대기 필터, 포차 하위 메뉴, 로컬 저장, 모바일/태블릿/데스크톱 가로 넘침, 콘솔 오류와 비공개 파일 404를 검사합니다.

폰트 출처·이용조건: `assets/fonts/LICENSES.md`.

## 전체 원고 등록

원고집 001–181 전체를 수록했습니다. 시험 등록한 045·038·128은 기존 순서와 객체를 보존했고 나머지 178편을 원고 순서로 추가했습니다. 같은 장면의 다른 메시지 버전도 별도 항목입니다. 본문·화자·등장인물·장면·출처 번호 및 원고 구간 전체(sourceExcerpt)를 보존합니다. 상태는 초안이며 분류는 제목의 《장소》를 사용하고 없는 경우 미정입니다.

추가 빌드나 서버 변경 없이 기존 data/archive.json을 사용합니다. 검색·분류 필터는 기존 에피소드 화면에 없습니다. 이전 브라우저 저장본은 자동으로 덮어쓰지 않으므로 편집실에서 원본 데이터 불러오기 후 검토·저장하세요.

node import-episodes.cjs는 보존된 data/episode-manuscript.md 원고집과 181개 항목을 대조합니다. --write는 기존 항목을 보존하고 누락된 항목만 추가합니다. npm run check에 원고 대조를 포함했습니다. browser-check.cjs는 181개 모달의 표시 본문과 출처를 검사하고 320/390/768/1280px에서 최장 원고 스크롤과 닫기를 검증합니다.

에피소드 모달은 화자와 원문 대사를 한 줄로 표시하고, 대사 사이 구분선과 불필요한 빈 줄 여백을 없앴습니다. 원고 데이터는 변경하지 않았습니다.

## GitHub Pages

배포 방식은 main 브랜치의 루트(/)에서 정적 파일을 게시하는 방식입니다. .nojekyll로 Jekyll 변환을 생략합니다. 모든 자산과 캐릭터 링크는 상대경로이므로 /token-pocha/ 하위 경로에서도 동작합니다. 추가 설치나 빌드는 없습니다.

예상 주소: https://bbo121.github.io/token-pocha/ (실제 배포 상태는 GitHub Settings → Pages에서 확인).

홈 복구 근거는 최초 구현 커밋 c382b24의 통계·세계관 서랍·하단 두 영역입니다. 큰 ARCHIVE STATUS 카드는 제외했습니다. 다른 페이지는 디자인을 유지하며 공개 사이트임을 나타내는 공통 표지만 WORLD ARCHIVE로 변경했습니다.

브라우저 검증은 TOKEN_POCHA_BASE_URL 환경 변수로 배포 주소를 지정해 동일하게 실행할 수 있습니다.
